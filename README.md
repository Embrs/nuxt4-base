# Nuxt 4 Base

企業級 Nuxt 4 前端框架樣板，使用 Vue 3 Composition API + TypeScript + Element Plus + Pinia。

專案規範詳見 [`CLAUDE.md`](./CLAUDE.md) 與 [`.claude/knowledge/`](./.claude/knowledge/)。

## 開發

```bash
npm install   # 安裝依賴
npm run dev   # 開發伺服器（port 3000）
npm run build # 生產構建
npm run preview
npm run lint
```

Node.js 版本需求：`>= 24.13.0`。
